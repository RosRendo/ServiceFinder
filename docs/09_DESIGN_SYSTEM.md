# 09: Design System Document
**Project:** Service Finder App

This defines the design tokens used across the application to ensure visual consistency.

---

## 1. Color Palette (Theme)

**Background & Surfaces**
- `bg`: `#F8FAFC` (Slate 50) - App background.
- `surface`: `#FFFFFF` - Cards, modals, bottom sheets.
- `border`: `#EBEBEB` - Dividers and light outlines.

**Primary Brand**
- `primary`: `#0A192F` (Deep Navy) - Main headers, primary buttons.
- `primaryLight`: `#F7F7F7` - Soft backgrounds for Navy elements.
- `accent`: `#3B82F6` (Blue 600) - Selection highlights, links, active tabs.

**Typography Colors**
- `text1`: `#0F172A` - Primary text (Slate 900).
- `text2`: `#475569` - Secondary text/Subtitles (Slate 600).
- `text3`: `#94A3B8` - Hints, placeholders, disabled text (Slate 400).

**Semantic / Status Colors**
- `success`: `#10B981` (Emerald Green) - Completed, Verified, Positive trends.
- `error`: `#EF4444` (Red) - Cancelled, Suspended, Danger actions.
- `warning`: `#F59E0B` (Amber) - Pending, Ratings, Warnings.

## 2. Typography System
*Font Family: Inter / System Default Sans-Serif*

- **Display (Hero):** 40px, Weight 800 (ExtraBold), Tracking -1px.
- **H1 (Screen Title):** 30px, Weight 800, Tracking -0.5px.
- **H2 (Section Title):** 18px, Weight 800.
- **Body 1 (Main Text):** 15px, Weight 500 (Medium).
- **Body 2 (Secondary Text):** 13px, Weight 500.
- **Caption:** 11px, Weight 600, Uppercase.

## 3. Spacing & Layout Tokens
- **Screen Padding:** 24px horizontal.
- **Section Gap:** 24px vertical.
- **Item Gap:** 12px vertical.
- **Border Radius:** 
  - `sm`: 8px (Inputs)
  - `md`: 12px (Small cards/icons)
  - `lg`: 20px (Main content cards)
  - `pill`: 9999px (Badges)
